安装 Edge 浏览器扩展

请使用 Microsoft Edge。保持 Clipboard Translator 运行， 再从 Edge 加载项商店添加扩展（需点一次「获取」确认）。安装后可自动与桌面配对。 本产品不上架 Chrome 网上应用店。

步骤
  1. 启动并保持 Clipboard Translator 运行（设置中启用「本机桥接」）。
  2. 用 Edge 打开下方按钮，在商店页确认获取扩展。
  3. 若尚未上架，可从 GitHub Release 下载扩展 zip，在 edge://extensions 用开发人员模式临时加载。
  4. 扩展安装后会尝试自动配对；失败时可在扩展弹窗输入桌面端 6 位配对码。

# 日计费展示（本机已用 + DeepSeek 余额）

## 口径

| 指标 | 来源 |
|------|------|
| 今日已用 | 本机 `history-YYYY-MM-DD.jsonl` 的 `cost_yuan` 合计（应用内估算） |
| 剩余 | `GET {base_url}/user/balance` 的 `total_balance`（优先 CNY） |

主窗底部独立 `billing` 行展示，例如：`今日已用 0.12元 · 剩余 98.5元`。单次翻译费用逻辑不变。

## 刷新时机

- 启动后异步拉余额，并立即汇总今日已用
- 每次翻译成功写入历史后：重算已用 + 再拉余额
- 本地缓存命中后同样刷新（余额一并拉取）
- 余额失败不打断翻译；尚无缓存余额时显示「余额暂不可用」，已有则沿用上次成功值

## 远期：Mac / 多机

每台机器各自用户数据目录，今日已用互不可见。若以后要多机合计，需另做历史同步或改用账户余额差值；本期不做。

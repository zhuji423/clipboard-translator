# 低成本上下文翻译

## 目标

翻译不再依赖进程内持续增长的隐式 messages，而是只携带来源明确、可预算、可清空的近期源文上下文，以改善代词、术语和多义词翻译，同时控制重复输入费用。

## 实现

- 普通剪贴板保留最近 5 分钟内的前 5 条原文；手动输入保持独立，问答继续使用独立连续会话。
- YouTube 扩展记录同视频实际经过的字幕，归并重复/重叠 cue；切视频、seek 或闲置 5 分钟后清空。
- 上下文单条最多约 500 Token、总计约 2000 Token；CJK 字符约按 1 Token、其它字符约按 4 字符 1 Token 估算，超限保留最近末尾。
- 桌面桥接重新校验扩展上下文，并用进程级 session 让应用重启和手动清空同步淘汰扩展旧字幕。
- 翻译请求使用稳定提示前缀和显式结构化上下文，不持久化历史译文；缓存键加入上下文指纹。
- 主窗口按翻译/问答模式复用清空按钮，托盘提供两个独立清空入口；上下文不写历史 JSONL。

## 验收

1. 相同原文在不同上下文中不会错误命中同一缓存。
2. 第 6 条淘汰最旧记录，5 分钟、seek、切视频、重启和手动清空均切断旧语境。
3. YouTube 跳过未划词字幕后再划词，模型仍能收到经过的前文；当前完整字幕与选中原文相同时不重复。
4. Python 测试、扩展上下文测试和生产构建通过；历史中仍只保存当前原文与译文。

# 按文种切换原文朗读音色

## 目标

翻译模式「原文」喇叭按文种选择系统离线语音：含汉字用中文音色，纯英文用英语音色，避免英语引擎硬读汉字发出类似字母的怪声。

## 实现

- `SpeechService` 启动时分别缓存英语（优先 en-US / en-GB）与中文（优先 zh-CN）音色；不硬编码 WinRT、SAPI 或具体嗓音名。
- `speak()` 用汉字范围 `U+4E00–U+9FFF` 判断：命中则切中文音色，否则切英语音色；中英混排走中文音色。
- 缺少当前文种音色时提示「未找到可用的系统中文/英语语音」，不回退到另一种语言。

## 验收

1. 复制英文点喇叭仍为英语音色。
2. 复制中文点喇叭为中文音色，不再出现字母怪声。
3. 中英混排走中文音色。
4. 仅有英语音色时读中文会提示且不播放。

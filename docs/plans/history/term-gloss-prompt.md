# 专有名词 / 标识符：保留原文并给出中文义

## 问题

当前 system prompt 要求「代码标识符、API 名一般保留不译」，模型对单独词如 `elapsed` 会原样返回，界面显示「完成」但用户看不到中文意思。

## 产品目标

- **短词 / 术语**：一定要能读到中文义（词典感），不只是回显原文。
- **整句翻译**：仍以通顺译文为主，不把每句拆成注释长文。
- **可复制**：需要保留标识符字形时，用「原文 + 括号短义」，而不是只丢中文、丢了检索用的英文词。

## 落地策略

采用 **「译文优先 + 术语括注」**：

| 输入形态 | 期望输出 |
|----------|----------|
| 孤立单词 / 短短语 | `原文（短义）`；多义用分号 |
| 句中的 camelCase / API | 句子照常译；必要时 `Name（短义）`，句意已清则可省略 |
| 路径、URL、大段代码 | 保持原样，不强行括注 |

## 完成工作（0.11.1 / 0.11.3）

- 更新 [`translator.py`](../../../translator.py) `_build_system_prompt`
- 更新 `_few_shot_messages`：短词给出含义（不再只回显原文）
- **0.11.3**：按用户反馈改为译文**只保留目标语短义**，不要 `原文（短义）` 括注形式；句中标识符也译成自然语言，不在译文里重复贴原文

## 非目标（仍不做）

- 单独「词典模式」开关
- 客户端规则分流标识符
- 多行讲解或 JSON 输出

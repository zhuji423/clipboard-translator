Privacy Policy

Clipboard Translator Subtitles (Microsoft Edge extension)
Last updated: 2026-08-09

Summary

This extension helps you look up words and translate short phrases from YouTube subtitles. It works together with the optional open-source desktop app Clipboard Translator installed on the same computer. The extension does not send your data to servers operated by the extension developer for analytics, advertising, or profiling.

Data the extension accesses

  • Website content (YouTube subtitles): when you use the feature, the extension reads the active subtitle line on the YouTube page and the word or short phrase you explicitly click or select.
  • Local settings: preference values such as feature on/off, target language, local bridge port, and a pairing token are stored with chrome.storage.local in your browser profile.

How that data is used

Selected subtitle text is sent only to the Clipboard Translator desktop app on your machine (loopback HTTP to 127.0.0.1, and optionally native messaging to obtain local bridge credentials). The desktop app performs lookup or translation using the API endpoint and API key that you configure. The extension package itself does not call cloud AI APIs and does not upload subtitle text to the developer.

What we do not collect

  • Name, email, address, age, or other contact details
  • Health, financial, or payment data
  • Passwords or account credentials for YouTube / Google / Microsoft
  • Emails, chats, or personal communications
  • Precise location or GPS
  • Full browsing history for advertising or analytics
  • Keystroke logging or background activity monitoring unrelated to the subtitle feature

Sharing and selling

We do not sell user data. We do not transfer subtitle text or settings to third parties for advertising, credit scoring, or unrelated purposes. If you configure a third-party AI API in the desktop app, that provider’s own privacy policy applies to the requests you choose to send there.

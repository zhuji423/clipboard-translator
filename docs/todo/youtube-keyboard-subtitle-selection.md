# YouTube 字幕纯键盘查词

## 一句话目标

把「听到生词 -> 暂停 -> 移动鼠标 -> 选词 -> 复制」缩短为纯键盘闭环：按 `Space` 暂停后自动选中当前字幕最后一个词，用方向键调整选区，再按 `Enter` 查义或翻译。

## 用户流程

1. 视频播放时按 `Space` 暂停。
2. 当前交互字幕的最后一个单词自动高亮；这个词通常就是用户刚听到并想查询的词。
3. 按 `Left` / `Right` 在当前字幕内逐词移动。
4. 按 `Shift+Left` / `Shift+Right` 从锚点扩展或收缩短语选区。
5. 按 `Enter` 智能提交：
   - 只选中一个词：调用现有语境查词链路，在页内弹层显示词义，不写系统剪贴板。
   - 选中多个词：调用现有短语翻译链路，同步剪贴板并唤起桌面翻译窗。
6. 按 `Esc` 先关闭查词弹层；无弹层时再次按下则退出键盘模式但保持暂停。
7. 按 `Space` 关闭弹层、退出键盘模式并恢复播放。

`Up` / `Down` 继续交给 YouTube 控制音量；退出键盘模式后，左右键恢复 YouTube 原有的进退行为。

## 交互状态机

- **进入**：视频产生暂停事件且当前字幕包含可选单词时进入；默认锚点和当前游标均为最后一个 `word` token。
- **例外**：鼠标点词查义所触发的插件内部暂停不得重新进入键盘模式，避免高亮末词覆盖用户点击的词。
- **移动**：普通左右键移动当前游标并折叠为单词选区；Shift+左右键保留锚点、移动另一端，从而扩选或收缩。
- **边界**：到达首词或末词后停止，不循环跳转。
- **请求**：移动到新词时不自动调用模型，只有按 `Enter` 才提交；开始新查询时使旧请求失效，旧响应不得覆盖新结果。
- **退出**：视频恢复播放、字幕消失、YouTube SPA 切换视频或扩展销毁时清空键盘选区。
- **避让**：输入框、搜索框、评论编辑区和其他 `contenteditable` 元素获得焦点时不拦截按键；带 `Ctrl`、`Alt` 或 `Meta` 的方向键保持原行为。

## 实现方案

### 1. 字幕选区

- 在扩展侧抽出可单测的 `WordSelectionState`，持有 `active`、`anchorIndex`、`focusIndex` 和规范化选区范围。
- 复用 [`extension/src/tokenize.ts`](../../extension/src/tokenize.ts) 的 `word` token 与现有按词索引拼接逻辑，保证鼠标拖选和键盘扩选得到一致文本。
- 在 [`extension/src/overlay.ts`](../../extension/src/overlay.ts) 增加进入、退出、移动、扩选和提交接口；使用背景色表示完整选区，使用不占布局空间的 `outline` 标识当前游标端。
- 保留现有鼠标点词、拖选、弹层拖动和缩放行为，不把键盘功能实现成鼠标事件模拟。

### 2. 视频与按键生命周期

- 在 [`extension/src/content.ts`](../../extension/src/content.ts) 监听视频 `pause` / `play`，管理键盘模式和字幕冻结。
- 键盘模式只拦截 `Left`、`Right`、`Shift+Left`、`Shift+Right`、`Enter`、`Esc` 和用于恢复播放的 `Space`。
- 为现有 `pauseForLookup()` 增加暂停来源保护，区分用户暂停和插件点词暂停。
- 弹层可见时移动选区应关闭旧弹层但保持暂停；恢复播放时取消活动请求并忽略迟到响应。

### 3. 既有接口复用

- 单词提交继续发送现有 `LOOKUP` 消息，使用当前字幕作为 `context`。
- 短语提交继续发送现有 `TRANSLATE` 消息，并沿用剪贴板尽力同步与桌面端 toast。
- 桌面端本机桥接协议、鉴权、LLM 配置和历史格式均不变。

## 验收标准

- 开启 YouTube CC 后播放视频，按 `Space` 暂停时最后一个单词立即高亮，视频时间不发生方向键跳转。
- 左右键逐词移动且首尾不循环；Shift+左右能扩选和收缩跨行字幕中的连续词。
- 单词按 `Enter` 打开语境释义且不污染剪贴板；多个词按 `Enter` 同步剪贴板并启动桌面翻译。
- 快速换词、重复提交时只有最后一次查词结果可以更新弹层。
- `Esc` 可退出键盘模式并恢复左右键进退；`Space` 可恢复播放。
- 无字幕、正在搜索或输入评论时不劫持按键。
- 鼠标点词、鼠标拖选、全屏、影院模式和 YouTube 站内切换视频无回归。

## 本期不做

- 不增加 B 站或通用网页字幕适配。
- 不解析 YouTube 逐词时间戳；当前字幕末词作为暂停时的默认候选。
- 不新增快捷键配置页；首版按键固定，后续根据实际使用再决定是否开放映射。
- 不增加自动查词、自动复制单词或按方向键即调用模型，避免剪贴板污染和不必要费用。
